# Fight3D

Простой 3D-файтинг в браузере: плоский пол, два бойца, бой против ИИ или онлайн с другом.

**Играть:** https://berolog.github.io/fight3d/

## Режимы
- **Против компьютера** — три уровня сложности.
- **Онлайн** — один игрок жмёт «Создать комнату» и отправляет другу код или ссылку, второй вводит код. Соединение напрямую между браузерами (WebRTC через PeerJS), сервер не нужен.

## Управление
| Клавиши | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | шаг влево / вправо (обход соперника) |
| J / K | удар левой / правой рукой |
| U / I | удар левой / правой ногой |
| Пробел | блок (держать) |
| C или Shift | присесть (держать) |
| Q / E | уклон влево / вправо |
| V | вид от первого лица / сбоку |
| Esc | выход в меню |

Раскладка клавиатуры не важна, работает и на русской.

Вид по умолчанию от первого лица. Пропущенный удар встряхивает камеру, а при падении она падает вместе с бойцом.

**Телефон или планшет:** перед стартом поставь галочку «Сенсорное управление». Слева появится джойстик для ходьбы, справа кнопки ударов, блока, приседа и уклонов.

## Как устроено
- Three.js, без сборки: просто статические файлы (`lib/` содержит Three.js и PeerJS).
- Человечек собран из примитивов, все анимации процедурные: позы + IK для рук и ног.
- Удар засчитывается по реальному касанию кулака или стопы с головой или корпусом. Пропущенный удар отбрасывает назад или в сторону, сильные удары и контр-удары сбивают с ног.
- Приседание спасает от ударов руками, но не от ног. Блок держит всё, уклон уводит от прямых ударов.
- Онлайн: хост считает физику, второй игрок отправляет ему нажатия и получает состояние.
